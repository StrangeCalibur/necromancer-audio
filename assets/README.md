# Application icon

`AppIcon.png` is the 1024-pixel RGBA master for Necromancer Audio Setup. The build produces the standard 16–1024 pixel macOS representations and packages them into `AppIcon.icns` before signing. The artwork is distributed under this repository's MIT license.

Created for this project on 2026-10-07 using the built-in image-generation tool, then resized with Apple's `sips`. No third-party logo or reference image was supplied.

Generation prompt:

> Use case: logo-brand. Create one finished macOS application icon for Necromancer Audio, an open source utility that revives vintage audio hardware. Square 1024 by 1024 composition. A striking, minimal ivory skull wearing chunky dark studio headphones, with a short bright emerald audio waveform forming the mouth. Friendly and confident, not horror or gore. Large simple shapes and strong silhouette legible at 32 pixels. Premium restrained macOS icon finish: charcoal rounded-square tile with subtly softened corners, gentle dimensional shading, a faint emerald rim light. Icon tile fills about 88 percent of image width, centered; transparent outside the rounded-square tile. No lettering, no wordmarks, no numbers, no extra props, no watermark, no scenery. The skull and headphones should read as a single beautifully balanced symbol, avoiding tiny decorative details.

The generator's original image was 1280 × 1280; the committed master is 1024 × 1024 with its transparency preserved.
